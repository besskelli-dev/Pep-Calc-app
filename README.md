# Pep Calc App

Safety-first peptide reconstitution calculator focused on reducing dose math mistakes.

## Features

- Reconstitution math with step-by-step breakdown
- Dose unit toggle (mcg or mg)
- Inline validation and guard rails for unrealistic entries
- Output mode toggle (units, mL, or both)
- Calculation timestamp and printable summary
- Pure calculator functions with automated tests
- Confidence check gate before calculations
- Installable PWA with offline cache

## Run

1. Install Node.js LTS
2. Run npm start
3. Open http://localhost:4173

Note: If node or npm are not recognized after install, restart the terminal or VS Code.

## Install As App (PWA)

1. Start the app with npm start
2. Open it in a Chromium-based browser
3. Use the in-app Install App button or browser install prompt

## Test

1. Run npm test
2. Verify all calculator math tests pass

## Notes

This app performs arithmetic only and is not medical advice.
